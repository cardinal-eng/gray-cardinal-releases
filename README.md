# Gray Cardinal

Десктоп-компаньон и внутриигровой аддон для **WoW Midnight**: показывает **DPS по M+ ключам
с Warcraft Logs** и встроенный Blizzard dungeon score для заявителей в Premade Groups (LFG).

- Регион: **EU**, интерфейс: **RU / EN**
- Исходный код закрыт; этот репозиторий — только **страница загрузок** (бинарники в [Releases](../../releases))
- О багах — [Issues](../../issues)

## Установка (Windows 10/11 x64)

1. Скачайте `gray-cardinal-<версия>-setup.exe` из [Releases](../../releases) (свежая — первой).
2. При запуске Windows может показать SmartScreen («С защитой вашего ПК»). Нажмите
   **«Подробнее» → «Выполнить в любом случае»** — установщик подписан самоподписанным
   сертификатом проекта.
   Чтобы предупреждение не появлялось: установите приложенный к релизу
   `gray-cardinal.cer` в хранилище **«Доверенные корневые центры сертификации»**
   (двойной клик → Установить → локальный компьютер → все программы автоматически).
3. JRE встроена в установщик — Java отдельно не нужна.

## Вход в Warcraft Logs (обязательно, 1 раз)

Запросы к Warcraft Logs идут **от вашего имени** через безопасный OAuth-вход (PKCE):
в приложении нет и не может быть никаких секретов, вводить ключи никуда не нужно.
(Механизм доступен начиная с v0.2.2.)

1. Настройки → секция **«Warcraft Logs»** → кнопка **«Войти через Warcraft Logs»**.
2. Откроется браузер — войдите в свой аккаунт Warcraft Logs и разрешите доступ.
3. Окно приложения покажет «Вход выполнен»; кнопка «Проверить соединение» — контроль.

Сессия сохраняется локально и переживает перезапуск; «Выйти» отзывает доступ.

## Аддон

Аддон входит в комплект: в настройках приложения есть установка бандла.
Ручная установка: скачайте `gray-cardinal-addon-<версия>.zip` из релиза и распакуйте в
`World of Warcraft\_retail_\Interface\AddOns` (внутри архива — папка `GrayCardinal/`).

## Целостность

SHA-256 каждого файла — в ассете `latest.json` релиза (и в тексте релиза):

```powershell
Get-FileHash .\gray-cardinal-<версия>-setup.exe -Algorithm SHA256
```

## Приватность

- Сетевые запросы — только к Warcraft Logs API (ваш OAuth-токен) и к Blizzard-данным в ответах WCL.
- Данных аналитики/телеметрии нет; настройки и логи — локально (`%USERPROFILE%\.graycardinal\`).
- Внутриигровая часть (аддон) не имеет доступа к сети — компаньон читает полосу пикселей
  с экрана (право «Запись экрана» не требуется на Windows).
